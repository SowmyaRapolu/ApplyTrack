
# 💼 ApplyTrack – Job Application Tracker

ApplyTrack is a Python-based job application tracking web application built using Streamlit and SQLite.

It helps users organize their job search, track application statuses, and monitor their progress through an interactive dashboard.

## Features

- Dashboard with application statistics
- Add new job applications
- View and search applications
- Filter applications by status
- Edit existing applications
- Delete applications
- Interactive analytics using Plotly
- Monthly application trend visualization
- SQLite database for persistent storage

## Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Plotly

## Installation and Setup

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate into the project folder:

   cd ApplyTrack

3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   streamlit run app.py
